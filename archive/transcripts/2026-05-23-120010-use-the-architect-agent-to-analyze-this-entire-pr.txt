  summary of project:                                                           
  **MediaVault** is a personal media archival and restoration system for        
  managing large ripped video files (movies, TV series, anime). The core        
  workflow is: **prep → split → push → archive → fetch → restore**.             
  - **main.py** (~1600 lines) handles everything local: hashing files with      
  SHA256, extracting tech specs via pymediainfo, splitting MKV files into ≤10GB 
   chunks using mkvmerge (with a balanced-split algorithm to avoid              
  keyframe-drift leftovers), pushing chunks to an Android Pixel phone via ADB,  
  replacing uploaded originals with tiny dummy placeholder files, and restoring 
   (merging chunks back) from downloaded files.                                 
  - **mainfetch.py** (~500 lines) automates downloading from Google Photos      
  using Selenium — it opens Chrome with a persistent profile, searches for      
  files by their embedded 6-char UID tag, triggers downloads via keyboard       
  shortcuts, monitors the Downloads folder, and routes files to the correct     
  restore folder.                                                               
  - The library is three JSON files (`library_movies.json`,                     
  `library_series.json`, `library_anime.json`) keyed by IDs like                
  `mov-en-2024-Inception` or `tv-TheBoyss01e01`, tracking file status through   
  states: `local_ready → onboarded → archived → restored_local`.                
  - Also this is a simple straight forward project which is already tested and  
  working. So the main files are main.py and mainfetch.py which contains code
